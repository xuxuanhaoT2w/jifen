# PUBG 实时多人记分板

四位玩家的人头差额与吃鸡分数自动结算的实时协作网页。打开同一房间链接的所有用户会立即看到彼此的修改。

## 多人协作方式

- 首次打开会生成房间号；点击“复制房间号”分享完整链接。
- 吃鸡列可勾选多位玩家。
- 每个编辑被服务端作为独立操作处理，因此不同人同时填写不同局次或不同玩家人头数时不会用整份表格覆盖对方内容。
- 房间状态持久化在 `data/rooms.json`；生产环境必须挂载持久化磁盘。

## 本地运行

```bash
npm install
npm start
```

访问 `http://localhost:3000`。从同一局域网的其他设备访问时，使用运行机器的局域网 IP 和端口 `3000`。

## 部署到 Render

1. 将本仓库推送至 GitHub。
2. 在 Render 创建 **Blueprint**，选择该仓库；它会读取 `render.yaml`。
3. 创建完成后，打开 Render 分配的 `https://...onrender.com` 链接，复制房间链接发给其他人。
4. 免费实例可能休眠；用于持续对局时请选择有持久磁盘的付费实例。

GitHub Pages 无法运行 WebSocket/Node 服务，不能作为实时多人版的部署目标。它仅适合静态、单机版本。
